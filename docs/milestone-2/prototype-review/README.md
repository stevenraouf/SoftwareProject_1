# AERIS frontend and Figma comparison

The comparison below records the frontend before implementation. The follow-up describes the changes and includes fresh comparisons from the running website. [Updated frontend and verification](implementation.md)

**25 November 2026 · Frontend commit `2a7dbca` · Partial match**

The Paris homepage carries the cabin window, destination photography, eight country choices and localized greetings into the website. The first substantial break occurs when a traveler enters a destination. On the Cairo screen, the website changes the composition, removes the city story and loses the route from the airport card to a dedicated flight draft. There are also visible differences in the cloud transitions, heading animation and logo replay. [Cairo side by side](images/desktop-cairo.jpg)

## Motion

The prototype timings below come from the saved native motion records. The website timings come from browser animation events and computed styles. Manual playback confirmed the visual sequence. Matching the duration by itself does not reproduce the movement.

| Effect | Prototype | Website |
| --- | --- | --- |
| Paris title | Characters appear along each line. The sampled desktop reveal finishes around 576 ms, and a pearl highlight peaks at 1,026 ms and settles at 1,476 ms. | Desktop and tablet use two 520 ms stepped clips, the second delayed 480 ms. Phone uses one 850 ms clip. The glass fill is static and has no timed highlight. |
| Destination greeting | The complete word fades in and rises 5 px over 480 ms. The sampled Cairo and Tokyo highlights peak at 930 ms. | The whole-word effect is present. It starts partially visible, scales and rises over 620 ms, without the later highlight. |
| Other page titles | Ordinary page headings type in, with static versions for reduced motion. | The headings on Flights, Stays, Planner and Journal had no animation on each of the three sizes with standard motion enabled. |
| Country shuffle | In tablet playback, the incoming Giza photo tilted and slid over the still-visible Paris photo inside the window. The sequence lasts about 465 ms and offers **Skip animation**. | Selecting a country replaces the image and animates only the incoming picture over 465 ms. There is no visible shuffle-skip control. |
| Explore a destination | Clouds gather over the outgoing home, cover the screen and reveal the arrival over about 825 ms. The control reads **Skip to destination**. | After the pathname changes, one static cloud image fades over the destination for 825 ms. The overlay responds to click or Escape and its accessible label is **Skip cloud transition**. It has no visible skip label. |
| Other page changes | Two cloud banks drift in opposite directions over a 350 ms ease-out. The overall passage uses a 140 ms entrance, 130 ms hold and 210 ms reveal. | The 480 ms overlay is skippable. The image’s opacity changes and the banks stay fixed. |
| Glass-button hover | The rim catches light for 160 ms on entry and settles over 130 ms on exit. | The shadow and entire button move over 160 ms in each direction. |
| Logo reflection | A narrow reflection crosses an already complete signature over about 1.1 seconds. Replay also offers a still pose. | The header has a 1.1-second reflection. Its small inline replay lacks the prototype’s standalone presentation and still control. |

The native records used were `CABIN_MOTION.md`, `LETTER-LIGHT-CHECK.json`, `DESTINATION-GREETINGS.json` and `FROSTED-TYPING-PLAYBACK.json` in the project’s delivered Figma archive. The earlier homepage tests set reduced motion for layout captures. The new observations exercised both motion settings. ## Coverage and limits

Six targeted Edge scenarios completed against the production frontend and a disposable local backend. They covered the three viewport sizes, 24 destination/size combinations, cloud skipping, replay, return navigation, the reduced-motion preference and computed title styles on four additional public pages. A passing scenario means that its assertions about observed behavior held. Several observations document differences. [Browser observations](browser-observations.json)

The archived graph contains 748 named states reachable from the supplied flows, including design-review and service examples. The ledger identifies their native frame IDs. The journey appendix compares representative states across all 15 guide chapters, including the seat picker, e-ticket, journal, trip planner and staff overviews. Individual layers and all 748 states have not been replayed and visually compared. The verified differences establish that full prototype parity has not been achieved.
